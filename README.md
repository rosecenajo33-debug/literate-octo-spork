# Lakbay Pilipinas — Travel & Tourism Website

A responsive travel and tourism website highlighting six destinations in the Philippines. Built for an academic project using **HTML5 and CSS3 only**.

## Project structure

```text
my-website/
├── index.html
├── about.html
├── gallery.html
├── css/
│   └── style.css
├── images/
│   └── (add your own downloaded image files here)
└── README.md
```

## Pages

- `index.html` — homepage, featured destinations, travel inspiration.
- `about.html` — travel guide, planning tips, and travel experiences.
- `gallery.html` — destination guide featuring Palawan, Boracay, Bohol, Siargao, Batanes, and Banaue/Batad in the Cordillera.

## Technologies and features

- HTML5 semantic structure
- CSS3 styling, Grid, Flexbox, media queries, transitions, and a CSS keyframe entrance animation
- Responsive layouts for desktop, tablet, and mobile
- Working page navigation and in-page anchor links
- Accessible image alternative text and navigation labels
- No JavaScript, JavaScript libraries, frameworks, or scripts

## How to run locally

1. Download or extract the project folder.
2. Open `my-website` in Visual Studio Code.
3. Open `index.html` in a browser.
4. Use the navigation links to visit the other pages.

The site uses remote images from Unsplash and Google Fonts, so an internet connection is needed for those assets. You may download appropriately licensed images and place them in `images/` if you want local image files. Update the image `src` and CSS background URLs accordingly.

## Publish with GitHub Pages

1. Create a **public** GitHub repository (for example, `my-website`).
2. Upload the contents of this folder to the repository root. Keep the folder structure unchanged.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish. The address will look like `https://YOUR-USERNAME.github.io/my-website/`.

## Customization

- Edit the text in the three HTML files to personalize the travel content.
- Change colors and layout in `css/style.css` using the CSS variables at the top.
- Replace remote image URLs with your own image files in `images/`.

## Image and content note

Destination descriptions are introductory travel inspiration, not live travel advice. Check current weather, transport schedules, local advisories, entrance requirements, and protected-area rules before traveling. Verify image licensing and attribution requirements before public or commercial reuse.
